# Prioritizing Potential Aquaculture

[Link to homework webpage](https://eds-223-geospatial.github.io/assignments/HW4.html)

Date: 27/11/2025

## Description

This repository contains all the materials for Homework Assignment 4 of the course EDS 223: Geospatial Analysis & Remote Sensing.

For this assignment, I practiced:

- Combining vector/raster data
- Resampling raster data
- Masking raster data
- Map algebra
- Creating a function

## How to Run

Fork and clone this repository to your local environment.

Open the `.qmd` (Quarto) document.

Ensure that the required R packages are installed.

Render the document to generate the analysis and maps in PDF format.
